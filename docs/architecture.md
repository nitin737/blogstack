# Architecture

This document describes the high-level architecture of the blogging platform.

## Services

- **Auth Service**: Handles user authentication and token generation.
- **User Service**: Manages user profiles.
- **Post Service**: Manages blog posts.
- **Comment Service**: Manages comments.
- **Engagement Service**: Manages likes and shares.
- **Subscription Service**: Manages user subscriptions to other users/topics.
- **Notification Service**: Sends notifications.
- **Search Service**: Indexes and searches content.
- **Analytics Service**: Tracks user behavior.
